# ✨ Features

## 📱 Responsive Design
- Fully responsive for desktop and mobile
- Instagram-style mobile top navigation
- Mobile bottom navigation bar

## 📸 Story Section
- Instagram-like story rings
- Clickable story viewer
- Auto story switching using JavaScript timer

## 🖼️ Dynamic Posts
- Posts rendered dynamically using JavaScript
- Supports both images and videos
- Professional Instagram feed UI

## ❤️ Interactive Features
- Like button toggle effect
- Hover animations
- Smooth UI transitions

## 👤 Profile Page
- Dedicated profile page
- Responsive post grid layout
- Project showcase section

## 🎨 Premium UI
- Dark mode Instagram design
- Clean spacing and alignment
- Modern visual appearance

# 📦 Installation & Setup


Simply open:

```bash

```

in your browser.
